# WILDBOUND MVP — Scope Lock

## Goal
Prove that the core creature-collector loop is fun in 15–20 minutes before producing a full game's worth of content.

## Build now
- One settlement + one route
- Three stage-1 creatures total
- Ratelit fully realized as the flagship creature
- One simple wild encounter
- One 1v1 turn-based battle loop
- Commands: Strike, Skills, Guard, Item, Run
- Defiance instinct playtest
- One Wildbond interaction
- One small mystery beat
- One save slot
- Minimal Party / Atlas / Inventory shells

## Explicitly not in MVP
- Evolutions
- Day/night
- Shops
- Sanctuary Trials
- Full quest framework
- Multiple biomes
- Full Wild Current plot reveal
- 20–30 creatures
- Online features
- Mobile release

## Exit criteria
A new player can start the game, move through one route, meet Ratelit, enter a battle, understand Defiance, finish the encounter, save, reload, and want to keep playing.
